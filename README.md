# debiderryberry.com

Static clone of https://debiderryberry.com (cloned 2026-11-26), unmodified HTML as served.

Pages: `/`, `/appearances`, `/autographs`, `/biography`, `/characters`, `/contact`,
`/kids-music`, `/music`, `/voiceover-help` — each stored as `<page>/index.html`
so the existing links work on any static host.

Note: images, audio, CSS and JS are still loaded from `voiceactor.net` and
`debiderryberry.voiceactor.com`; they must be brought local before the old host is cancelled.
